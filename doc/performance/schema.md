# Формат результатов

`run-NNN/` содержит:

- `metadata.env` — версия кода, профиль, машина, affinity и состояние среды;
- `warmup.gob`, `warmup-report.json` — отдельный прогрев Vegeta;
- `results.gob` — сырой измеряемый прогон Vegeta;
- `samples.csv` — одна строка на запрос, latency в наносекундах;
- `report.json` — отчёт Vegeta;
- `server.log` — вывод JVM этого запуска.

`runs-summary.csv` содержит одну строку на запуск. `combined-summary.json`
объединяет только валидные запуски серии. Перцентили считаются по всем их
индивидуальным latency, стандартное отклонение — выборочное (`n - 1`).

Запуск валиден, если каждый ответ имеет ожидаемый HTTP-статус и Vegeta сообщает
`success = 1`.
