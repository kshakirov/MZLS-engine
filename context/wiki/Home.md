# MZLS-engine Wiki

[English](#english) · [Русский](#русский)

## English

MZLS-engine is an experimental Java HTTP engine built to study byte-oriented
parsing, explicit state machines, compact binary representations, and
measurable server behaviour.

The project favours explicit offsets, primitive values, and formally described
transitions over hidden allocation and framework machinery. Implemented facts,
accepted decisions, and open research questions are documented separately.

### Start here

- [Architecture](Architecture) — what exists in the current code.
- [Engineering Decisions](Engineering-Decisions) — the ADR registry and the

- [Performance](Performance) — reproducible benchmarks and profiling.
- [Research](Research) — unresolved questions, formal models, and experiments.
- [Development](Development) — entry points for building, running, and testing.

Current focus: the experimental [Binary Router](Architecture-Binary-Router).

## Русский

MZLS-engine — экспериментальный HTTP-движок на Java для исследования
побайтового разбора, явных автоматов, плотных бинарных представлений и
измеримого поведения сервера.

Проект предпочитает явные смещения, примитивные значения и формально описанные
переходы скрытым аллокациям и механике фреймворков. Реализованные факты,
принятые решения и открытые исследовательские вопросы документируются
раздельно.
